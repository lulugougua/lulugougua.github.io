WINDOWS · 个人自用

把日程，放在桌面上。

一个个人使用的 Windows 日历组件。月历与接下来的安排常驻桌面右侧，需要处理日程时，点击打开完整 Google 日历。

只读同步，修改在完整日历里完成。

组件通过 Google 官方 Calendar API 读取日历列表和日程。它不会创建、修改、分享或删除日历内容。

组件提供什么

  • 桌面月历，支持查看其他月份和返回今天。
  • 读取从今天起未来 31 天内、已选中日历及主日历中的日程，包含重复、全天和跨天安排。
  • 每 5 分钟同步一次，并支持手动刷新。断网时显示上次成功同步的缓存与同步状态。
  • 点击日程或底部按钮，打开本机封装的 Google 日历应用。该网页应用与组件授权各自独立。

账号与数据

首次连接通过系统浏览器进行 Google OAuth 授权。组件仅申请日程读取和日历列表读取权限。授权信息在本机通过 Windows 加密功能保存，日程缓存保存在本机应用数据目录；本组件没有开发者运营的数据服务器。

本网站仅用于介绍应用及说明数据使用方式，不提供 Google 登录入口，不读取你的日历。使用前请阅读隐私政策与使用条款。

项目与联系

本应用为个人自用的非官方项目，不由 Google 提供或认证。仅采用 Google 官方 API 与授权流程。应用支持联系信息以该项目 Google OAuth 授权页面配置的用户支持邮箱为准。
