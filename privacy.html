桌面日历隐私政策使用条款
数据使用说明

隐私政策

更新日期：2026年10月31日

本政策适用于该个人自用 Windows 桌面日历组件及其介绍网站，说明当前版本访问、使用、保存和分享数据的方式。

1. 访问哪些 Google 数据

经你在系统浏览器中授权后，组件访问你的日历列表及 Google 日历中已选中日历、主日历从今天起未来 31 天内的日程。组件向 Google 申请两个只读权限：

  • calendar.events.readonly：读取日程。
  • calendar.calendarlist.readonly：读取已订阅日历列表。

组件用于显示和缓存的数据包括日历名称、日程标题、开始及结束时间、全天标记和相关标识。Google 接口返回的数据可能含有其他日程字段；当前版本不把这些字段作为日程缓存保存。组件不请求修改或删除日程的权限。

2. 如何使用数据

数据仅用于显示桌面月历、日程列表、同步状态及恢复最近一次成功同步的内容。组件默认每 5 分钟同步，也可由你手动刷新。不将 Google 用户数据用于广告、出售、建立广告画像、训练通用人工智能模型或与其他数据聚合。

3. 数据保存在哪里

OAuth 应用凭据和授权令牌通过 Electron 的 Windows 本机加密功能保存。用于离线显示的日程缓存以 JSON 文件保存在本机应用数据目录，未额外加密；它受你的 Windows 账户与文件访问权限保护。本应用没有开发者运营的日历数据服务器。

导入的原始 OAuth JSON 下载文件由你自己管理。删除组件内的授权记录不会自动删除该原始文件。

4. 向谁传输或分享

组件通过 HTTPS 向 Google 的授权服务和 Calendar API 发起授权、续期和只读同步请求。开发者不会通过组件将你的日历数据上传到其他服务或提供给其他人。Google 按其隐私政策处理相关请求。

封装的完整日历窗口直接加载 Google 日历网站，该窗口中的登录、网站数据和你主动打开的外部链接受对应网站政策约束。

5. 保留、断开和删除

日程缓存保留至下次成功同步覆盖、你点击设置中的“断开本机连接”，或你自行清理应用数据。“断开本机连接”删除本机授权令牌和日程缓存，但保留导入的应用客户端配置。完整清理时还需退出应用并删除其本机应用数据目录；单独删除程序安装文件不会自动删除用户数据。

你可以随时在Google 账号的第三方连接页面撤销授权。在 Google 侧撤销授权不会自动删除已有的本机缓存，请按上述方式清理。

6. 网站访问

介绍网站是静态页面，不含日历同步、登录表单、广告或分析脚本。若由 GitHub Pages 托管，托管服务可能根据其隐私声明处理 IP 地址等访问日志。访问本网站不会将你的日程或授权令牌发送给托管服务。

7. Google API 数据使用承诺

本应用对从 Google API 获取的信息的使用与向其他应用的转移遵守 Google API Services User Data Policy，包括 Limited Use 要求。

8. 联系与更新

项目维护和支持联系信息以项目 Google OAuth 配置中的用户支持邮箱为准。数据处理方式变化时，应同步更新本政策及应用内说明。
